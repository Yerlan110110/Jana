## Реальные ошибки и исправления

| Наблюдение | Причина и исправление | Повторная проверка |
| --- | --- | --- |
| Первый cloud build не находит backend при COPY | Vercel использовал каталог Dockerfile как build context. Worker Dockerfile перенесён в корень | Облачная сборка и запуск Daemon PASS |
| Ready перенаправляется на путь со слешем и получает 404 | Начальный service ingress не принимал итоговый Django URL. Использованы маршруты `/(.*)` | Ready и все облачные API-пути PASS |
| Cross-role вход возвращает 500 | Supabase session pool исчерпал 15 клиентов при постоянных Django соединениях. Включены transaction pool, `CONN_MAX_AGE=0`, запрет server-side cursors и prepared statements | Реальные входы, бизнес-записи и 20 параллельных ready PASS |
| Квитанция есть в базе, страница остаётся в ожидании | Request detail сохранял первый ответ fulfillment без обновления. Добавлен опрос только `delivery.state=queued`, с остановкой при ошибке или конечном состоянии | Тот же публичный сценарий PASS без перезагрузки и увеличения timeout |
| Первый native pytest использовал 120/min | Проверочный runner наследовал браузерный лимит вместо обычных 10/min | Исправленный PostgreSQL проход 234 PASS с обычным лимитом |
| Отдельный Docker запуск конфликтует с портом 8000 | Проверочный env сохранял порт по умолчанию | Указаны собственные порты, прежний стенд не затронут |
| nginx replacement отказывается запускаться | Новый явно принадлежащий проверке Compose project отсутствовал в allowlist | Добавлен точный project и передан его env file. Replacement PASS |
| Первый cloud Academy не входит | Chromium сообщает `net::ERR_NETWORK_CHANGED` на POST login, без ответа сервера | Одна повторная проверка Academy PASS. Не менялись пароль, limiter или timeout |

Неудачные логи сохранены. Они не заменены зелёными результатами.

## Повторить браузерные проверки

Публичный сценарий находится в `tests/public/demo.e2e.ts`. Он допускает точный `https://jmhr.vercel.app` при `JANAMEN_PUBLIC_PROJECT=jmhr` и совпадающем `PUBLIC_HOST`. Не расширяйте его на произвольную production-базу.

Облачные модульные сценарии используют существующие `tests/web/knowledge-loop.e2e.ts` и `tests/web/academy.e2e.ts`, выбранные через `e2e.config.ts`. Они изменяют вымышленные записи. Только их собственные новые документы и курсы архивируются в конце.

Репозиторий содержит сценарии и команды воспроизведения. Сырые отчёты и секреты этой машины остаются приватными под `.artifacts/vercel-deploy/`. Опорные файлы:

- `ci-final/results.json`, `ci-runtime-final/results.json` и соответствующие логи.
- `browser-cloud-pooled/` с воспроизведением застывшей квитанции.
- `browser-cloud-fixed/` с двумя успешными публичными проверками.
- `browser-cloud-modules/` с успешной HR-связью и исходным сбоем сети Academy.
- `browser-cloud-academy/` с успешным повторным сценарием Academy.
- `ready-concurrent.json`, `cloud-inspect.log`, `cloud-daemons-final.log` и `decisions.tsv`.

Снимок страницы входа дополнительно сделан в T3 collaborative browser по короткому адресу. Этот снимок подтверждает открытую страницу входа. Его пониженное качество не используется как доказательство типографики или полного визуального соответствия. Secret-filled автоматические сессии не имеют заявленного просмотра скрытых screenshots.

## Применённые методы и ограничения

Pstack и `show-me-your-work` разделили ошибки сборки, БД, отображения и проверочного стенда. Fix Root Causes направил исправление на обновление fulfillment, поскольку worker уже завершил работу. Type System Discipline сохранил модель из OpenAPI вместо новой копии состояний. Fstack, оригинальный Emil и Jakub сохранили текстовый подтверждённый статус и существующий retry. Новая анимация или новый набор компонентов не нужны. Опрос использует установленный TanStack Query v5 и прекращается по данным сервера.

| Before | After | Why |
| --- | --- | --- |
| «Ожидает доставки» остаётся после прихода квитанции | Пока delivery queued, обновляется настоящий fulfillment; accepted показывает прежний текст квитанции | Пользователь получает подтверждение без повторного входа или ложного успеха |

Это ограниченная проверка исправленного поведения. Полный обзор всех областей `better-interface` и всех визуальных состояний в этой поставке не заявлен. Открытый COV1 и независимый R3 остаются в `docs/continuation-status.md`. Лимит делегирования текущего запуска исчерпан. Новый независимый reviewer облачной конфигурации и журнала решений не запускался. Собственная проверка не является независимым approval.

Не проверены настоящие 1C, Documentolog, выплаты, юридические подписи и генерация LLM. Бесплатные инфраструктурные квоты и beta-статус Vercel Services и Daemons ограничивают надёжность стенда. Материалы защиты ещё требуют репетиции и сокращения к трём минутам.
