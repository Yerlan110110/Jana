# Материалы защиты JanaMen

[Презентация PDF](JanaMen-defense.pdf). Три страницы: последствия настройки, реальный публичный экран репетиции и архитектура продукта.

[Сценарий 60 секунд речи и 120 секунд демо](../product/jury-demo-script.md).

Сайт https://jmhr.vercel.app. На странице входа откройте «Демонстрационные роли» и выберите сотрудника, руководителя или HR. Пароль для публичного демонстрационного входа не нужен.

## Источник и сборка

Актуальный генератор: `scripts/defense/build_keynote.py`. Запуск из корня:

```bash
.artifacts/tools/defense-pdf-venv/bin/python scripts/defense/build_keynote.py
```

Зависимости: `scripts/defense/requirements.txt`, установленные DejaVu Sans. Исходный снимок публичной репетиции: `assets/public-impact.png`. Люди и регламент вымышлены. Проверены все три отрендеренные страницы. Старые `slides.json`, `build_pdf.py`, HTML-памятки описывают предыдущую презентацию и не являются источником текущего PDF.

## Границы

255 тестов PostgreSQL, 22 сценария ролей и 10 клавиатурных проверок относятся к локальному стенду. Полный маршрут новой редакции через вопрос сотруднику и статус команды отдельно не принят. Интеграции 1С и Documentolog демонстрационные. Время выступления ещё не измерено.
