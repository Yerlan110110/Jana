## Границы доказательств

Новый экран снят с локального Docker-стенда 18 октября. Он показывает
изменение источника при сохранении подходящего заголовка документа.
Это не семантическая или юридическая проверка правила.
`tests/web/knowledge-loop.e2e.ts` проверяет новый источник, изменение,
потерю источника и скрытие устаревшего результата при редактировании.
Публичное развёртывание и замер выступления проверяются отдельно.

## Изменить документ

Текст и ссылки находятся в [slides.json](slides.json). Исходные PNG и их происхождение находятся в [assets/provenance.json](assets/provenance.json). Это снимки отдельных видимых областей, а не доказательство полного просмотра каждого экрана.

Сборка использует [ReportLab 5.0.1](https://pypi.org/project/reportlab/5.0.1/) и установленные DejaVu Sans. Шрифт содержит кириллицу. Его исходное уведомление сохранено рядом с изображениями. В интерфейс на снимках входят прежние Inter Tight и Geist Mono с их собственными лицензиями.

```bash
uv venv .artifacts/tools/defense-pdf-venv
uv pip install --python .artifacts/tools/defense-pdf-venv/bin/python \
  -r scripts/defense/requirements.txt
.artifacts/tools/defense-pdf-venv/bin/python scripts/defense/build_pdf.py
```

На другом компьютере передайте доступные TTF через `--regular-font` и `--bold-font`. Генератор проверяет высоту текстовых блоков и выводит контрольные суммы PDF, исходного текста, шрифтов и PNG. После изменения отрендерите и просмотрите все три страницы заново. Сохранённый PDF не требует Python или шрифтов на компьютере докладчика.
