# Каталог из 30 курсов и данные для проверки интерфейса

Статус: спецификация оригинального демонстрационного содержания, сверенная с объединённым seed 17 октября 2026 года. Реальные материалы, правила и персональные данные Jana Post в этом документе не используются. [Свежий машинный отчёт](../verification/evidence/demo-baseline.json) подтверждает 30 курсов, 60 уроков, 90 вопросов и 12 702 слова материала. Таблицы ниже объясняют замысел; точный опубликованный текст находится в версии курса, созданной из seed.

## Объём и смысл каталога

Каталог содержит 30 различных курсов в шести категориях. У каждого курса есть отдельный результат обучения, материал и соответствующие ему вопросы. Изменение только заголовка не создаёт новый курс.

Для каждого курса seed создаёт как минимум два содержательных урока и три разных вопроса с объяснением правильного ответа. Урок включает ситуацию, правило демонстрационного процесса, пример и действие сотрудника. Ориентир объёма материала одного курса составляет 350–700 русских слов. Это проектная цель качества контента, а не уже измеренный объём реализации. Ни длительность чтения, ни посещение страницы не заменяют проверяемого результата.

Таблица ниже задаёт план двух уроков и один опорный вопрос. Автор seed добавляет ещё два вопроса по тому же материалу. Вопросы проверяют применение правила в ситуации. Все численные условия согласования, выдачи аванса и тестирования должны быть явно демонстрационными. Курсы не заменяют официальное обучение технике безопасности, трудовому праву или обработке опасных грузов.

Колонка "Кому полезен" описывает учебную цель. Она не предоставляет права в приложении. Базовый синтетический каталог может быть виден всем трём ролям одной области доступа. Изучение курса про согласование не даёт сотруднику возможности согласовать заявку.

## Согласованная структура материалов

Демонстрационная версия курса фиксирует название, порядок уроков, обязательность материала, вопросы, варианты и правила оценки. Изменение текста опубликованного урока создаёт новую версию. Уже выданное назначение продолжает ссылаться на свою версию.

Для каждого вопроса хранится объяснение правильного ответа. Ключи ответов находятся в seed и серверной модели. Learner API не отдаёт правильные ответы до разрешённого контрактом разбора попытки и никогда не отдаёт все ключи вместе с вопросами перед сдачей. Публичный исходный код содержит синтетические демонстрационные ключи. Это не защищённый экзамен и не средство аттестации реальных сотрудников.

В базовом сценарии отсутствует таймер экзамена, если API не реализует серверное измерение времени. Интерфейс сообщает число вопросов, опубликованный порог и правило повторных попыток. Значения получает из действующей версии курса. Он не выдумывает универсальный порог или число попыток.

Названия и краткие описания имеют поля для RU и KZ. В текущем seed заполнены казахские названия всех 30 курсов, но краткие описания, уроки и вопросы остаются русскими. `content_language` показывает фактический язык версии. Полный перевод и его редакторская проверка остаются отдельной работой.

### Основной набор Даны

По умолчанию каталог содержит 30 опубликованных курсов. Дане назначены 24 разных курса. Остальные шесть доступны в каталоге без назначения. Фактическую возможность самостоятельно записаться определяет API. Отсутствие назначения не создаёт кнопку несуществующей команды.

| Ось | Распределение в 24 назначениях | Проверка |
| --- | --- | --- |
| Завершение | 8 завершены, 6 начаты и не завершены, 10 не начаты | 8 + 6 + 10 = 24 |
| Просрочка | 5 из 16 незавершённых имеют прошедший `due_at` | Просрочка является подмножеством незавершённых, не новой взаимоисключающей колонкой |
| Скорый срок | 4 других незавершённых имеют срок в следующие 7 календарных дней | Не смешивать с просроченными. Правило интервала показывает интерфейс |
| Попытки | У 2 из 6 начатых есть неуспешная попытка. У 3 завершённых есть прежняя неуспешная и последующая успешная попытка | История неудачи не отменяет более позднее успешное завершение |
| Обязательность | 18 обязательных, 6 рекомендованных | Обязательность независима от начала и завершения |
| Язык | Русский материал у всех 24; казахское название у каждого курса | Полные KZ-варианты пока не опубликованы |

Эти количества подтверждены [манифестом первого полного наполнения](../verification/evidence/demo-baseline.json). Последующие HTTP-проверки добавляют собственные записи, а сроки меняются с течением времени. UI получает актуальные количества по API и никогда не вставляет эти цифры константами.

### Дополнительные проверочные варианты

| Вариант | Изменение реального набора | Какое состояние проверяется |
| --- | --- | --- |
| Новичок | Нет заявок, нет попыток, несколько новых назначений | Пустая история не выглядит ошибкой. Первое действие понятно |
| Все завершены | Все назначения одного сотрудника завершены | Нельзя показывать искусственную просрочку ради заполнения экрана |
| Архив | Один из 30 курсов архивируется после завершения | Каталог и история расходятся осмысленно. Исторический результат сохраняется |
| Новая версия | У существующего курса публикуется новая версия | Старые назначения и попытки не переписываются |
| Неполные данные | Отсутствует необязательная длительность, нет руководителя, нет фотографии | Интерфейс не показывает ложные значения и случайный placeholder-аватар |
| Конфликт | Два разрешённых клиента получают одну версию заявки, один принимает решение | Второй получает 409 и путь обновления |
| Отказ провайдера | Настроенный генератор недоступен | AI показывает фактический режим ответа и сохраняет вопрос |
| Недоступный источник | Источник отозван после ответа | Ссылка проверяет актуальный доступ. Нельзя вернуть сохранённый скрытый фрагмент |
| Большой список | Разрешённая таблица содержит несколько страниц заявок и уведомлений | Поиск и сортировка действуют на всю серверную выборку |

Состояния loading, network error и 409 вводятся через тестовую границу данных будущего компонента. Не создавайте невозможные бизнес-значения ради красивой страницы состояний. Приёмку этих вариантов описывают [state contracts](state-and-data-contracts.md) и [quality gates](quality-gates.md).
