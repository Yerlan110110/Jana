# Продолжить готовый JanaMen. Только дизайн

Последнее поручение владельца. Продолжить этот репозиторий с облачным агентом, поправить дизайн и подготовить сдачу. Пользовательский frontend уже реализован и связан с Django API. Не создавайте starter и не считайте прежний backend-only handoff нынешней точкой старта.

Прочитайте [инструкцию облачному агенту](CLOUD_DESIGN_HANDOFF.md), затем AGENTS.md, HANDOFF.md и [текущий статус](docs/continuation-status.md). Оригинальные задания находятся в docs/briefs/. [Сценарий защиты](docs/product/jury-demo-script.md) рассчитан на пять минут и двух участников. Команде нужна [наглядная памятка](docs/defense/team-map.html), без лекции по программированию.

Сохраняйте оба кадровых процесса, 30 курсов, права, историю, обработку ошибок и реальные API. Сначала откройте продукт и выясните желаемые изменения дизайна по конкретным экранам. После правок проверьте затронутые пути в браузере и выполните CI перед push.

[Прежняя широкая инструкция](docs/archive/CODEX_START-before-cloud-design-20261018.md) сохранена для истории. Её слова о неготовом frontend устарели. Незавершённая полная приёмка COV1 остаётся открытой.
